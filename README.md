# Imposter Game Setup
## Overview
Setup for a fun party game where one random player becomes the 'imposter' and the others receive a secret word. 
## Instructions
1. Enter how many players are playing and click "Start"
2. First player (player who clicked start) sees word or "You are the Imposter!", clicks "Hide", and passes phone to next player
3. Next player clicks "Next", sees their role/word, and clicks "Hide" before passing the phone to next playyer
4. Repeat step 3 until everyone has a role
5. Reload page to replay!
## Features
- Dynamically loads words from a CSV file
- Pretty pink theme <3
## Made Using
- HTML, CSS, JS
